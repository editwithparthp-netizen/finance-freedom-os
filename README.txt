FINANCE FREEDOM OS — PHONE SETUP
1. Upload the CONTENTS of this folder to the ROOT of a public GitHub repository.
2. Keep index.html, manifest.webmanifest and sw.js in the repository root.
3. Upload the icons folder too, preserving both PNG files.
4. GitHub repository Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Wait for GitHub Pages to publish, then open the published HTTPS URL in Chrome.
6. Chrome menu > Install app / Add to Home screen.

This is a browser-based educational planner. It is not financial advice. SIP calculator outputs are hypothetical. The app stores entries in browser local storage on this device; clearing browser data may erase them. Trading journal is for paper practice only.
